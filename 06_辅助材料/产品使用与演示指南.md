# 数问 InsightAI 产品使用与演示指南

## 产品用途

数问 InsightAI 将自然语言问题转换为可执行、可复核的数据分析结果。系统支持医疗、通信、金融结构化数据，以及从文档表格中提取证据并计算。

## 页面说明

| 页面 | 用途 |
| --- | --- |
| 数据源管理 | 查看官方数据准备状态，导入 CSV、Excel、SQLite 数据 |
| 数据概览 | 查看领域、数据表、行数、字段类型、空值和脱敏样例 |
| 智能问数 | 输入自然语言问题，查看 SQL、结果表、指标、图表和结论 |
| SQL 安全测试 | 验证只读 SQL 规则并查看危险操作拦截结果 |
| 表格问答 | 按任务编号定位文档表格，查看问题、答案、计算过程和证据 |
| 分析报告 | 汇总问题、SQL、结果、耗时与数据口径 |
| 官方评测 | 查看六类任务状态、执行率、答案非空率和失败记录 |

## 推荐操作流程

1. 启动程序并打开浏览器中的本地地址。
2. 在“数据源管理”确认官方数据缓存状态为已准备。
3. 在“数据概览”选择领域并查看字段说明。
4. 在“智能问数”输入问题；需要调用大模型时，先在启动程序前配置 API 密钥。
5. 查看结果表中的筛选字段和查询条件核对信息，再按需展开 SQL 或开启图表。
6. 在“表格问答”选择任务集与任务编号，检查答案和来源证据。
7. 在“分析报告”查看分析留痕，在“官方评测”查看运行状态及指标口径。

## 代表性问题

- 医疗基础查询：统计当前启用的科室数量。
- 通信条件筛选：找出所有在北京的女性用户。结果表应显示省份、城市、性别及筛选条件核对。
- 通信趋势分析：统计已有月份的每月账单总额，按月份升序排列并生成趋势图。
- 金融分组统计：统计不同类型的客户数量。
- 文档表格计算：使用公开样例查看计算结果及对应的证据行列。

## 指标口径

结构化 SQL 执行率表示查询成功运行的比例；非结构化答案非空率表示任务获得非空输出的比例；证据留存率表示答案记录中保留来源证据的比例。这些指标不等同于答案准确率。未公开标准答案的任务不报告全量准确率。

## 常见问题

- **网页打不开**：确认启动终端仍在运行，并访问启动脚本显示的端口地址。
- **端口已占用**：使用启动脚本显示的实际地址；不要重复启动多个服务实例。
- **没有配置 API 密钥**：仍可运行公开样例、查看已有结果及体验安全校验；实时生成新查询需要密钥和网络。
- **结果只显示数字**：带有“多少、数量、人数、总数”等统计意图的问题会显示统计结果；“找出、列出、所有、明细”等列表意图会返回明细表。
- **结果表看不到筛选依据**：检查表格中的城市、省份、性别等字段以及“查询条件核对”列。

## 数据与隐私

数据分析在本地完成。发送给模型的内容限于相关表结构、字段说明和必要的少量样例；敏感字段在页面、报告和演示画面中默认脱敏。API 密钥通过本机环境变量或未提交的 `.env` 文件配置，不应放进交付材料。
