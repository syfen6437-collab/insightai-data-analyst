# 数问 InsightAI 演示视频讲解稿

## 0:00 至 0:30 数据准备

这是数问 InsightAI 智能数据分析助手。系统已经完成内置数据集的本地准备，共覆盖 1,467 道任务、24 张结构化表和 787 个非结构化任务块。

## 0:30 至 0:58 数据概览

数据概览使用 SQL 聚合生成字段画像，不会把百万级数据整表加载到 Pandas。页面显示字段类型、空值数量和脱敏样例。

## 0:58 至 1:56 结构化问数

在通信任务中选择公开样例。系统保留标准 MySQL 8 SQL，同时转译为 DuckDB SQL 本地执行。UI 通过外层查询限制预览行数，不会修改原始 SQL。

## 1:56 至 2:14 安全拦截

安全模块使用 sqlglot 解析 AST。DROP、DELETE、DDL、环境操作和多语句都会在执行前拦截，安全机制独立于模型提示词。

## 2:14 至 3:00 表格问答

非结构化任务按任务 ID 精确取回证据。公开样例只需要两行信用利差数据，参考答案为负 2.86%。系统保留使用行列和计算过程，不上传整份 Markdown。

## 3:00 至 3:15 分析报告

报告汇总问题、正式 SQL、执行状态、耗时和数据口径。结果展示默认脱敏。

## 3:15 至 4:00 官方评测

当前数据准备完成率和任务索引完整率均为 100%，公开样例 6 项全部通过。全量 1,467 道任务均有结果或明确失败记录：结构化 SQL 成功执行 663/680，执行率 97.50%；非结构化任务返回非空答案 786/787，非空率 99.87%，证据留存率 100%。没有隐藏标准答案，因此不把这些指标称为全量准确率。
